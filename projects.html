PowerShellintune-autopilot-usb-enrollment

Autopilot Hash Upload (USB)

300 new laptops needed Windows Autopilot registration. This toolkit registers each one from the Windows setup screen with a flash drive: no CSV import and no sign-in on the laptop.

  • Reads the serial and hardware hash, and keeps an offline CSV backup on the drive
  • Uploads the hash to Intune through Microsoft Graph using an Entra app registration
  • Waits for Intune to confirm the import, then shuts the laptop down
  • PowerShell
  • Microsoft Graph
  • Intune
  • Autopilot
  • Entra ID

M365 Offboarding Automation

Offboards a Microsoft 365 user end to end when an agent ticks one checkbox on a Zendesk ticket, instead of visiting several admin centers by hand.

C#windows-device-reset-automation

BreakFix Toolkit

A portable, drop-and-run pre-wipe checker for Windows technicians. Remote onto a machine, run one EXE, and know exactly what is safe before you wipe it.

  • Checks disk health, BitLocker recovery-key backup, OneDrive, browsers, Outlook data, drives and printers
  • Produces a Migration_Report.html with a clear READY TO WIPE banner
  • Backs up bookmarks and a password-protected vault for Wi-Fi and BitLocker keys, then restores on the new PC
